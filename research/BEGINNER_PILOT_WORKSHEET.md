# Build Quest Academy beginner pilot

Run the first session with 3–5 people who have never shipped an Android app. Give each participant the updated Academy prototype and Habit Check-in ZIP, an Android device or emulator, and their own clean working folder. For the cloud exercise, prepare a disposable development project with two confirmed test accounts. Use separate data per participant.

## Participant tasks

| Task | What the participant should show | Result |
|---|---|---|
| 1. First run | Open the starter on Android, change the title and show it on the screen. | |
| 2. Save and recover | Add a habit, close and reopen the app, reproduce the practice failure, then show that one retry produces one item. | |
| 3. Independent change | Add a completed count or another small feature. Explain how they verified it. | |
| 4. Two-account proof | Show that each disposable account can add its own habit and cannot see the other account’s habit. | |
| 5. Release order | Explain preview testing, signed bundle upload, Play-installed retest, and applicable closed testing in the right order. Record actual Play tests separately when account access is available. | |
| 6. Review | Complete a challenge, miss a question, and retrieve it in Review. Return the next day to check a question previously answered correctly. | |

## Facilitator record

Let the participant read and act before offering help. Record participant ID, operating system, device and Expo Go or development-build path. For each task, mark **independent**, **with hint**, **blocked**, or **skipped with reason**. Note time, the exact point of confusion, the hint given, and the observable result. Preserve only redacted evidence. Ask “What did you expect to happen?” when a participant gets stuck.

Use the pilot to prioritize fixes. A repeated blocker in startup, saving, or account isolation needs another pass on a clean setup. Treat the curriculum as ready for beginners when participants can complete the core tasks with the guide and explain how they know their app worked.
